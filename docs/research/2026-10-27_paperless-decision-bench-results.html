01Corpus & Method

What was tested

Corpus pulled from the live archive (read-only, runtime-minted DRF token): 10 receipts (Bill-doctype paragony: Carrefour, Tamashi Sushi, Paro, WTK…), 10 invoices (gmail-sourced Hetzner / GitHub / Google Workspace / faktura-VAT), 10 general documents (drive-import: Registerauskunft, job emails, payment confirmations), 8 encrypted bank statements (text-arm only — images never leave the LAN). Ground truth = owner-curated paperless metadata. Page-1 images rendered from originals at ≤1400px — no OCR involved in the image arm.

Questions per document (one API call, both answers parallel)

doc_class (Choice: receipt / invoice / bank_statement / letter_or_other) and is_accounting (Noul: “an invoice or receipt for goods or services”). Scoring maps the corpus class general → expected letter_or_other; encrypted statements score only the Noul (no readable content ⇒ no honest doc_class truth). Model: jev-latest → answered as jev-1.14.0. 66 calls total (28 image + 38 text), zero API errors in the final run.

02Findings

Receipts and invoices: perfect, pre-OCR, sub-500ms

18/18 receipts and 20/20 invoices classified correctly across BOTH arms — including thermal-paper paragony read from the raw page-1 image with no OCR. Latency p50: 446ms (image) / 368ms (text). This is exactly the consume-path triage signal the archive lacks today.

Every “miss” is a label problem, not a model problem

General class: 5/10 image, 6/10 text. All 9 misses are semantically defensible model answers against noisy labels — Starbucks and Super-Pharm → receipt (they ARE receipts), Google Payment confirmations → invoice, P298276 → invoice. A 2-minute owner label audit likely moves overall accuracy to ~96%.

Confidence saturates — gate on margin, not confidence

Jev’s confidence is ~1.0 on correct AND wrong answers alike (mean 0.99 vs 1.00). A ≥0.9 confidence gate admits 27/28 docs and keeps every miss inside it. The top-2 probability margin is the likelier gate signal — already returned in every answer, not yet scored.

Encrypted statements: honest non-answer

8/8 empty-content statements → letter_or_other with is_accounting noul 0.09–0.10: correctly excluded from accounting flows despite zero signal — the right behavior for the encrypted-statement class.

04Bugs Hit Live (all fixed in-session)

Fixed

Binary payloads must never cross argv

scripts/paperless-decision-bench.sh (jev_call / clef_call)

Three successive failures, each caught by the run itself: jq --rawfile on a binary JPEG silently corrupts bytes (UTF-8 sanitization); a >128KB base64 string as --arg exceeds Linux MAX_ARG_STRLEN; curl --data-binary "$req" hits the same argv cap.

Fix base64 to a temp text file → jq --rawfile (ASCII-safe) → curl --data-binary @- via stdin.
Fixed

Scorer truth-mapping bug

--score

Corpus class general never matched model option letter_or_other — correct answers scored wrong. Headline drifted 0% → 32% → 64% → 82% across four runs. Numbers above come from the verified mapping (classes reconciled against raw TSVs after the fix).

Known

load_secrets required all providers

--bench

A Jev-only run died on the Cloudflare PLACEHOLDER check — the owner’s exit-code-1. Now per-provider.
