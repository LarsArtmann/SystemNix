04What We Should Improve

Pre-deploy checklist for dependency upgrades

We jumped straight into editing without a systematic checklist. A pre-commit checklist should include: (1) read upstream changelog, (2) check for new required env vars, (3) verify overlay interface unchanged, (4) update AGENTS.md, (5) run flake check, (6) deploy, (7) run post-deploy-check.

nix flake check --no-build is unreliable

The nix flake check --no-build fails because upstream's nix/web.nix uses builtins.readFile on a derivation output that requires building. This is a pre-existing issue unrelated to our update, but it means we can't use flake check as a gate. Consider using nix eval on specific config paths instead.
