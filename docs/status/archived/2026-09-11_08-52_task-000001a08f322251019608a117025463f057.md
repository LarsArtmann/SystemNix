## e) WHAT WE SHOULD IMPROVE

1. **Queue done-filter.** A dispatch whose work item is already `[x]` in TODO_LIST with a matching Task-Queue-ID commit should be auto-skippable. Impact: saves one wasted dispatch per closed item; the agent-side idempotency check (grep TODO_LIST + `git log --grep Task-Queue-ID`) took 2 calls and should be the documented first step of every queue contract.
2. **Contract step 3 is ambiguous for zero-change runs.** "Verify your work: run the project's build and tests" — when the run makes no changes, building is pure cost on a pressure-sensitive box (QLC NVMe, oomd history). The contract should say: "if and only if you changed derivations."
3. **Doc-claims-vs-live-verification drift.** The prior session wrote "every ~5 min" from a snapshot; the circuit breaker (1h backoff) was already deployed upstream but not re-checked. Lesson (recurring class in this repo): every cadence/counter claim in AGENTS.md gets one journal re-verification when the file is touched — same discipline as "status reports are point-in-time."
4. **Permanently-red Gatus checks deserve self-documenting names.** "DiscordSync Turso Sync Active" is red BY DESIGN for potentially months; a `deliberate-red` tag or renamed check ("… Stale-Mirror Signal (expected RED)") would stop every future on-call (human or agent) from re-diagnosing it. Config-only, ~10 min.
