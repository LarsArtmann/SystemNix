2. **Root-cause anomalies, don't hand-wave them.** "First build passed, second failed on the same expression" deserves an answer, not a shrug. Suspect: eval-cache staleness under daemon races — possibly a NEW instance of the "daemon stale-fetch/eval cache" class already documented in AGENTS.md.

Improvement: bump procedures should grep AGENTS.md for the old version string as a mandatory step (I did update all three spots this time).
4. **The sops declare-without-key class blocks ALL deploys atomically.** A parallel session declaring a secret mid-flight takes the whole tree's deployability hostage. Improvement idea: eval-time or pre-deploy warning when a declared sops key is absent from its encrypted file — the failure currently only surfaces at manifest FOD time (i.e., at deploy), never earlier.
5. **The extras diff was manual** — a small flake check comparing enabled extras against upstream pyproject (like `gatus-pattern-lint`) would make future hermes bumps mechanical instead of careful.
6. **Consider tag-pinning the hermes input.** Upstream merges ~4.5k commits / 4 days; every unrelated lock refresh rides main HEAD. A `?ref=`-pinned tag cadence would shrink bump blast radius — at the cost of the update-nag staying on between tags (user decision).
