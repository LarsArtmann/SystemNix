The fixture assertion only protects this one fixture; the class (any script writing `-foo` files + the daemon's no-review auto-commit) is repo-wide. 2. **Extend the fixture's junk assertion to the drill's scratch extract dir.** Today it checks only the fixture script's invoking cwd; extract-side stray files in `$scratch` would go unnoticed. S.
3. **Make the pre-commit hook amend-aware.** On `--amend` the staged diff is empty, so the staged-file lint legs silently no-op (observed live this run, §b2) while the message claims "All validation checks passed". When the staged tree is empty and HEAD is being rewritten, lint HEAD's tree (or the upstream-diff range) instead. S-M.
