## e) WHAT WE SHOULD IMPROVE

1. **Session-end commit gate for queue dispatches:** every queue session must end with either a footer commit or an explicit "nothing to commit" proof. The queue's re-dispatch check is the only thing that catches a footless landing, and it costs a paid dispatch to run. A cheap `git log -1 --format=%B | grep Task-Queue-ID` assertion in the session's own exit path would have saved this re-dispatch.
2. **Daemon-commit interplay:** the daemon's heuristic sweeps are net-positive (they preserve work), but any ticked TODO row in a daemon commit is a "session died before committing" signal. Worth a one-line note in docs/CONTRIBUTING.md's daemon-race section: *ticked-but-footerless ⇒ check for a dead sibling session before re-deriving the work.*
3. **The promoted `scripts/takeout-rename-loop.sh` is fixture-proven only.** Its 8 legs are hermetic and good, but no run has pointed it at a REAL staging root. A live `--once` pass against account #2's complete staging (7 parts, should complete instantly) would prove the parts.tsv-driven count path against production data.
4. **The hardcoded `~/.cache/takeout-probe/rename-loop.sh` still exists on disk** (verified live this session; not currently running). Now that the generic wrapper is in `scripts/`, the hardcoded copy is a split-brain risk: two loops that fold zips, one pinned, one generic. It should be retired (or repointed) the moment racedriver8k's G1 resolves — queued in §f.
5. **Check-vs-app namespace confusion (§d.3):** trivial, but `nix run .#<checkname>` failing obscurely burned a cycle. The flake could expose the takeout batteries as apps too, or the docs could pin the canonical invocation.
6. **Selftest floor growth is manual:** every new battery or leg extension required a hand edit to the `case` block in `flake/parts/checks/selftests.nix` (intake 7→12, rename-loop new 8). The floor is doing its job (a deleted leg fails the build), but the floors themselves drift unless someone remembers to bump them; the prior session did, correctly — a `--emit-floor` mode on the selftest runner that prints the exact Nix line would make future bumps copy-paste.
