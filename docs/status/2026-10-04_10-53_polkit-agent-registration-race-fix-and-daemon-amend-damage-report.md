## e) WHAT WE SHOULD IMPROVE

1. **Amend-forward on this box needs a hard carve-out:** `git commit --amend` into daemon commits is only safe WITHOUT pathspec AND after `git show --stat` proves the daemon commit is exactly yours. Amend-with-pathspec into a daemon commit is a content DELETION mechanism, not a message fix. (Documented in CONTRIBUTING rule 5 this session — the rule now exists because the failure did.)
2. **Staged-set guard before every commit:** `git diff --cached --numstat | wc -l` (and eyeball the list) immediately before `git commit` — costs 2 seconds, catches the daemon's mid-flight `git add` of foreign files (rule 6). Should be muscle memory for every agent session; ideally the pre-commit hook enforces it (sibling row already queued by the parallel session).
3. **Post-deploy polkit leg should assert an agent OWNS the slot**, not merely that no aborts occurred — the dead-agent-no-owner state is invisible to the current grep (and is exactly the state this system sat in for a day). A gdbus GetConnectionUnixProcessID probe against the session bus (with `DBUS_SESSION_BUS_ADDRESS` set from `/run/user/<uid>`) turns "no crash" into "someone answers".
4. **Exclusive-slot ownership should never be decided by start-order luck** — two agents racing a DBus registration is the same shape as two modules claiming one vHost. The durable rule (now in gotchas): wiring must NAME the winner. Any future "second component also registers X" needs the first one disabled in the same changeset.
5. **"Fixed it" close-outs must name the surface** — the 2026-08-18 "adwaita/fusion fixed polkit" claim was true for the HM platformTheme surface and silently false for the niri-flake unit surface; the recurrence cost 191 crash-loops and a day of dead auth. (Already a codified rule; this is its second live demonstration — now recorded in gotchas with the incident.)
6. **The daemon's squash cycle is a content hazard, not just a message nuisance** — it lost committed-and-verified doc content once this session (recovered because I re-checked). A daemon-side honor-file/lock (already tracked upstream per policy rule 4) is the real fix; until then, agents should treat "committed" as "verify with `git show HEAD:<file>` before walking away".
7. **DMS deserves a service runbook** (docs/services/dms.md) — polkit ownership, the DMS_DISABLE_POLKIT/DMS_DISABLE_MATUGEN envs, the split-brain settings.json mechanics, and the restart-registration caveat are scattered across agents/desktop.md today; this session added a fourth scattered fact.
