## e) WHAT WE SHOULD IMPROVE

1. **Tests that encode the buggy premise are worse than no tests.** The old auth tests only covered "no file → flow, file → skip" — they PINNED the bug as correct behavior. Rule for this repo: every "authenticated" claim must be tested against a DEAD-grant fake, not just a missing file. (Partially addressed: 5 new cases do exactly that.)
2. **One source of truth per health question.** The same grant question had four answers (CLI presence, old `/health` presence, UI "transient", journal truth). The fix composed existing primitives instead of adding a fifth truth — keep that discipline: new surfaces must CONSUME `VerifyAuth`/`gmail_aggregate`, never re-derive.
3. **Neuter/restore cycles must be single-command and git-free.** My mutation revert via `git checkout` was the session's worst moment. The SystemNix rule ("keep negative-test neuter/restore cycles ATOMIC (single shell command)") exists — InboxClean sessions need the same reflex: `sed` in, `sed` out.
4. **Never amend onto a shared-tree HEAD.** Twice burned. The daemon-race discipline (verify `git show --stat HEAD` before amend) is necessary but not sufficient when the daemon commits DURING the pre-commit hook run. New default: pathspec-commit on top, squash later if the history matters.
5. **Pre-commit linter auto-fixes create silent staging divergence.** BuildFlow's golangci-lint auto-fix modified files AFTER `git add`, so my commit captured pre-fix content and the worktree held post-fix content (invisible split-brain until inspected). Improvement: re-`git add` after the hook, or run lint before staging.
6. **`gmailAccountStatus` has side effects inside a "read status" call** (it runs `tryReconnect` with backoff). Surprising for a function named like a getter — the dashboard now calls it on every load. Worth refactoring into probe (pure) + heal (explicit) halves.
7. **Stale generated files across templ bumps.** The 12 regenerated `_templ.go` files differed purely by generator style — the committed ones predated the go.mod templ bump. A CI freshness guard (`templ generate && git diff --exit-code '**_templ.go'`) would keep generated code honest.
