## b) BUGS CAUGHT DURING VERIFICATION (the test earned its keep)

1. **The disk-busy awk had a zero-delta bug**: with `m` unset, a 0 delta never set it, and the `m == ""` sentinel printed -1 (unknown) — so a TRUE idle-disk phantom reported "unknown ⇒ corroborated" and TRIPPED. The phantom scenario 8b caught it; fixed with `BEGIN { m = -1 }`.
2. **The fake diskstats line had 12 stat fields instead of 11**, so `$13` was a filler, not io_ticks — the busy delta read 0 and masked the real scenario. Field layout corrected (9 fillers, ticks at $13).
3. **The busy% value assert was timing-flaky**: elapsed between the seeded epoch and the guard run is integer seconds, so 12000 ms delta printed 40.0 at elapsed=30 but 38.7 at 31. The assert now requires the metric KNOWN (not -1) — the trip itself is only reachable with busy ≥ 20, so corroboration stays proven.
