## e) WHAT WE SHOULD IMPROVE

1. **Footer-commit hygiene under the daemon.** When working a queue item: stage + commit the moment artifacts are final (the daemon sweeps every ~10 min), and never leave the footer commit "pending until the end of the session". If swept, the amend path works — but only with the `git show --stat` verification the doctrine mandates.
2. **`nix derivation show` jq trap deserves an AGENTS line:** its output is wrapped (`{derivations: [...], version}`) — the naive `.[].outputs…` path silently yields empty and makes realization checks lie. Alternative that cannot fumble: `nix build --no-link --print-out-paths` + `nix path-info <out>`.
3. **fsync-bench.sh `--load` has no free-space guard.** The dd streams write at the writeback rate for up to `LOAD_CEIL=900s` — potentially hundreds of GB into the target fs. On the QLC root that is an ENOSPC invitation (the box already rode the 99.76% cliff once). Add an available-space check before spawning load (refuse if headroom < a few GB × streams), and/or `LOAD_BYTES` cap / `oflag=direct` option.
4. **Fix the "direct-write" wording** in the 00-25 report (§a/§b row 5-6 label) or the script header — the load is buffered writeback; say so, so nobody cites it as an O_DIRECT number.
5. **`migrate-hot-db.sh finalize` doesn't GATE on the prepared count.** prepare verifies src==dst counts; finalize only PRINTS the live-subvol count — a file dropped between prepare and finalize would pass silently. Persist the prepare count (e.g. `$STAGING/.migrate-hot-db-count`) and fail finalize on mismatch.
6. **`migrate-hot-db.sh finalize` leaves an empty staging dir tree** (`--remove-source-files` strips files, not dirs; `rmdir` fails on any non-leaf). `find "$STAGING" -depth -type d -empty -delete` before the rmdir — cosmetic but stops every wave ending in a WARNING.
