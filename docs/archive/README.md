# Historical Documentation Archive

Non-status historical material: superseded guides, one-off session reports,
evaluations, and migration-era documents from the `~/Desktop/Setup-Mac` era.

## Layout

- `docs/archive/` (this dir) — non-status archive: old guides, one-off reports,
  evaluations, migration-era docs. Status reports do NOT live here.
- `docs/status/` — current status reports (living inbox).
- `docs/status/archived/` — ALL archived status reports (single canonical
  location since 2026-09-14; the former `docs/status/archive/` and
  `docs/archive/status/` trees were folded in).

## Rules

- Documents are preserved as-is for historical accuracy. Old path references
  (`~/Desktop/Setup-Mac`) are intentionally NOT rewritten.
- Do NOT follow setup/deployment instructions from here — use `docs/`,
  `docs/runbooks/`, `docs/services/`, and `AGENTS.md` for current guidance.
- Do not delete documents without explicit approval.
