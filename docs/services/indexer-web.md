# indexer-web (docs index Web UI)

**Service:** `services.indexer-web` — `modules/nixos/services/indexer-web.nix` wrapping upstream `inputs.index.nixosModules.indexer-web` (`github:LarsArtmann/index?ref=master`, package pinned explicitly — SystemNix nixpkgs carries no `indexer-web` attr). URL: `index.home.lan` (**Layer 2 protected** vHost), port 8105 (`lib/ports.nix`), loopback bind. DNS `index` in `platforms/common/dns-local.nix`.

Always-on, event-sourced view over the project documentation state: scans `~/projects` (upstream scanner: README/docs discovery per project), stores domain events in its own SQLite (`/var/lib/indexer-web/events.db`), serves a fleet table + per-project detail pages. Complements (does not replace) the `docs-archive-stats` user timer (daily TSV history in the index repo).

## What it serves

| Route          | Auth      | What                                                     |
| -------------- | --------- | -------------------------------------------------------- |
| `/`            | none      | Dashboard (fleet docs table, scan status, changelog)     |
| `/projects/X`  | none      | Per-project docs detail                                  |
| `/scans`       | none      | Scan history                                             |
| `/openapi.json`| none      | API surface                                              |
| `/metrics`     | none      | Prometheus text (`indexer_projection_lag_seconds`, `indexer_scan_in_progress`, `indexer_dlq_events`, …) |
| `/admin/*`     | `X-Api-Key` | rescan, DLQ list/replay/purge, projections list/reset, status |

## Ops

- **Scan cadence:** full scan on every start (`scanOnStart`) + daily rescan (`scanIntervalSeconds` default 86400). `Type=simple` — the listener opens after the first scan completes; until then the Gatus check is honestly red. Force a rescan: admin `POST /admin/rescan` (or restart the unit).
- **Admin API key:** machine-local random (`searxng-secret-key` doctrine, NOT sops) generated by `indexer-web-secret-key` (boot oneshot, idempotent) into `/var/lib/indexer-web-keys/admin-key` (root 0600) and injected via `LoadCredential` → the binary reads `$CREDENTIALS_DIRECTORY/admin-key`. Read it: `sudo cat /var/lib/indexer-web-keys/admin-key`. Call admin: `curl -H "X-Api-Key: $(sudo cat /var/lib/indexer-web-keys/admin-key)" -X POST https://index.home.lan/admin/rescan` (admin chain is also rate-limited 5/min upstream).
- **Runs as `lars` (primaryUser), NOT DynamicUser** — `/home/lars` is 0700, a dynamic uid can never traverse the scan roots (mr-sync posture). Upstream's `DynamicUser = true` is plain-valued, hence `mkForce false`. `ProtectHome = read-only` comes from upstream (derived from searchPaths under /home). State dir `/var/lib/indexer-web` is lars-owned via `StateDirectory`.
- **OTel:** the binary reads its own `INDEXERWEB_OTEL_ENDPOINT` (URL-parsed — scheme REQUIRED) → `http://localhost:4318`; the registry's standard `OTEL_EXPORTER_OTLP_ENDPOINT` rides beside it as the house contract. Registered in signoz-coverage (`wiring = "env"` via the integration registry, `maxAgeHours = 720`).
- **Monitoring:** Gatus "Indexer Web" (`/` HTML body) + "Indexer Web Metrics" (`indexer_scan_in_progress` presence) — both via the integration registry entry; `indexer-web` in system-health monitored units; Homepage tile `index` (Development group).
- **Restart:** `sudo systemctl restart indexer-web` (restarts re-scan on start; the key oneshot is `Requires=`+`After=` and converges idempotently).
- **Delete/DLQ recovery:** projections are rebuildable (`POST /admin/projections/reset` with key); the event store itself is re-seedable by a full rescan — no backup entry by design (state is derived from ~/projects).

## Related

- `docs-archive-stats` (HM module, same upstream flake): daily `indexer docs-stats --record` TSV snapshots into `~/projects/index/docs-stats-history.tsv` — the longitudinal history; indexer-web is the live view.
- Upstream `nixosModules.default` (`services.indexer` timer/watch) is deliberately NOT enabled: report/summary generation in a projectDir with `ProtectHome = yes` — useless for /home scan roots and redundant with docs-archive-stats.
