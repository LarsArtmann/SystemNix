# NixOS [Community]

:::note
This is a community contribution and not officially supported by the Immich
team, but included here for convenience.

Please report issues to the [NixOS/nixpkgs issue tracker][nixpkgs-issues].
:::

## Installation

Immich is shipped as a NixOS module in
[nixpkgs](https://github.com/NixOS/nixpkgs/blob/master/nixos/modules/services/web-apps/immich.nix).
Enable it in your NixOS configuration:

```nix
{
  services.immich.enable = true;
}
```

This provisions PostgreSQL (with the `pgvector` extension), Redis, and the
machine-learning service, and listens on `localhost:2283`. Media files are
stored in `/var/lib/immich` by default (`services.immich.mediaLocation`).

For hardware-accelerated transcoding, grant the service access to your GPU
device:

```nix
{
  services.immich.accelerationDevices = [ "/dev/dri/renderD128" ];
}
```

For any setting not exposed as a first-class option, use
`services.immich.settings`, which accepts the same shape as the
[config file][config-file]:

```nix
{
  services.immich.settings = {
    server.externalDomain = "https://immich.example.com";
    ffmpeg.accel = "vaapi";
  };
}
```

Secrets can be loaded from a file by setting an attribute to
`_secret = "/path/to/file"` — the file is read by systemd at service start
(`LoadCredential`) and never enters the Nix store:

```nix
{
  services.immich.settings.oauth.clientSecret._secret = "/run/secrets/immich-oauth";
}
```

## Backups

Immich's built-in database backup works out of the box — the module provides
`pg_dump` and `gzip` to the server. The database only contains metadata; back
up your `mediaLocation` separately.

## Known issues

- [nixpkgs#490345](https://github.com/NixOS/nixpkgs/issues/490345) — changing
  `services.immich.mediaLocation` after the first start breaks existing
  libraries (asset paths are stored in the database)
- [nixpkgs#526809](https://github.com/NixOS/nixpkgs/issues/526809) — when
  using an external PostgreSQL 18+ server
  (`services.immich.database.enable = false`), the bundled `pg_dump` is older
  than the server and the built-in backup job fails

For other issues, open one at [NixOS/nixpkgs][nixpkgs-new]; the convention is
a `nixos/immich:` title prefix.

[nixpkgs-new]: https://github.com/NixOS/nixpkgs/issues/new/choose

Immich is shipped as a NixOS module in
[nixpkgs](https://github.com/NixOS/nixpkgs/blob/master/nixos/modules/services/web-apps/immich.nix).
The module provisions PostgreSQL (with `pgvector`), Redis, and the

## Requirements

Same as the general [requirements](/install/requirements): minimum 6 GB RAM
and 2 CPU cores; a 64-bit Linux system running NixOS.

## Step 1 — Enable the module

```nix
{
  services.immich.enable = true;
}
```

Rebuild with `sudo nixos-rebuild switch`. Immich listens on `localhost:2283`.

## Step 2 — Hardware acceleration (optional)

Grant the service access to your GPU device (no user or group changes needed —
the module uses systemd `DeviceAllow`):

```nix
{
  services.immich.accelerationDevices = [ "/dev/dri/renderD128" ];
}
```

## Step 3 — Configuration

`services.immich.settings` accepts the same shape as the
[config file][config-file]:

```nix
{
  services.immich.settings = {
    server.externalDomain = "https://immich.example.com";
    ffmpeg.accel = "vaapi";
  };
}
```

To load secrets from a file without exposing them in the Nix store, set the
attribute to `_secret = "/path/to/file"`:

```nix
{
  services.immich.settings.oauth.clientSecret._secret = "/run/secrets/immich-oauth";
}
```

The file is read by systemd at service start via `LoadCredential`.

## Step 4 — Reverse proxy

The module listens on `localhost:2283`. To expose Immich behind a reverse
proxy, forward your domain to that port, e.g. with Caddy:

```caddy
immich.example.com {
  reverse_proxy localhost:2283
}
```

For nginx, see the [Post Installation][post-install] guide.

`pg_dump` and `gzip`). The database only contains metadata — back up your
